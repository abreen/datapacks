# Data packs

Minecraft: Java Edition data packs.

| Pack | Description | Minecraft |
| --- | --- | --- |
| [bed-tweaks](bed-tweaks) | Respawn at any bed you've placed, not just the last one | 26.3 |
| [boltcatcher](boltcatcher) | Catch lightning in a hopper and fight to keep its speed and low-gravity powers charged | 26.3 |
| [agent-api](agent-api) | A command API that lets any MCP-compatible AI agent query and build in the world over RCON, with [agent-bridge](agent-bridge) | 26.3 |
| [autobreed](autobreed) | Farm animals breed on their own until they get crowded | 26.3 |
| [death-tweaks](death-tweaks) | Keep inventory, but lose some items and experience on death | 26.3 |

## Installing

Run `./build.sh` to zip every pack into `dist/`, then copy the zip into your
world's `datapacks` folder (`saves/<world>/datapacks/`) and run `/reload`.
A pack folder can also be copied in directly without zipping.
