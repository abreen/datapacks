# Data packs

Minecraft: Java Edition data packs.

| Pack | Description | Minecraft |
| --- | --- | --- |
| [death-tweaks](death-tweaks) | Keep inventory, but lose some stacks and experience on death | 26.3 |

## Installing

Run `./build.sh` to zip every pack into `dist/`, then copy the zip into your
world's `datapacks` folder (`saves/<world>/datapacks/`) and run `/reload`.
A pack folder can also be copied in directly without zipping.
